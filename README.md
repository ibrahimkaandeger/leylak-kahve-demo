# Leylak Kahve & Fırın — Demo Kafe Sitesi

Küçük işletmeler için hazırladığım tek sayfalık tanıtım sitesi örneği. İşletme hayalidir.

**Canlı demo:** https://ibrahimkaandeger.github.io/leylak-kahve-demo/

## Özellikler
- Mobil uyumlu, framework'süz (HTML / CSS / JavaScript), hızlı açılış
- Kategorili menü (sekmeler)
- Rezervasyon formu → hazır mesajla WhatsApp'a yönlendirme
- Çalışma saatlerine göre canlı "Şu an açığız / kapalıyız" durumu
- Sabit WhatsApp butonu, harita, çalışma saatleri
- SEO: meta etiketleri, Open Graph, schema.org `CafeOrCoffeeShop` verisi

## Yeni müşteriye uyarlama
`script.js` başındaki ayarları değiştirmek yeterli: WhatsApp numarası, çalışma saatleri, menü.
Görseller `img/` klasöründe.

Görseller yerel olarak Z-Image modeliyle üretilmiştir.
